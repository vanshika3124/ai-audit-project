# User Interview Insights

### Target Audience
* **CTO of a Seed-stage Startup**: "We have so many AI seats (Cursor, ChatGPT, Midjourney) that we’ve lost track of who is using what. A quick audit tool is exactly what we need before our monthly burn review."
* **Freelance Web Developer**: "I use Claude and Cursor. I didn't realize that by switching to annual plans or consolidating seats I could save $400 a year. The 'Real-life comparison' feature (like the MacBook Pro) makes the savings feel real."

### Key Pain Points Identified
1. **Subscription Overlap**: Teams paying for both GitHub Copilot and Cursor.
2. **Zombie Seats**: Paying for seats for employees who no longer use the tool.
3. **Price Opacity**: Difficulty in comparing Team vs. Pro plans quickly.

### Feature Requests
* "I want to be able to download a PDF to show my finance head." (Implemented)
* "The tool should be fast—no long forms." (Implemented via Bento Grid UI)
