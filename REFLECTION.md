# Reflection

### Challenges Overcome
* **State Complexity**: Managing a dynamic list of tools where each entry had its own configuration (seats/bill) was challenging. I solved this using a React Record state to map tool IDs to their specific data objects.
* **UI/UX Refinement**: Iterating through multiple design versions to reach a "Bento-grid" and "Step-by-step" selection flow taught me the importance of user-centric design.

### Key Learnings
* Developed a deeper understanding of responsive design principles for professional SaaS dashboards.
* Learned how to integrate third-party services like Supabase for real-time data storage in a frontend-heavy application.
