# 🚀 Credex AI Spend Audit Engine

An intelligent audit tool designed to help startups and solopreneurs identify "leakage" in their AI subscription stacks. Built as part of the Credex Internship Assessment.

## 🔗 Live Demo
**[[https://aiauditt.netlify.app/](https://aiauditt.netlify.app/)]**

---

## ✨ Features
- **Defensible Audit Engine:** Real-time calculation of annual savings based on tool underutilization.
- **Lead Capture:** Seamless integration with Supabase to capture high-intent leads.
- **AI-Powered Insights:** Personalized summaries explaining the "Why" behind the savings.
- **Social Virality:** One-click sharing to LinkedIn to drive organic growth.
- **High-Fidelity UI:** Professional, dark-themed interface built with Tailwind CSS.

---

## 🛠️ Tech Stack
- **Frontend:** Next.js 14 (App Router), TypeScript, Tailwind CSS
- **Backend:** Supabase (Database & RLS)
- **Deployment:** Netlify
- **Documentation:** Markdown

---

## 📁 Project Structure
- `/src/app/lib/auditEngine.ts`: The core logic for calculating savings.
- `/src/app/lib/supabase.ts`: Database configuration and client.
- `ECONOMICS.md`: Deep dive into ROI and unit economics.
- `GTM.md`: Go-to-market strategy and distribution plan.
- `PRICING_DATA.md`: Source citations for AI tool pricing.
- `DEVLOG.md`: Day-by-day development journey.
